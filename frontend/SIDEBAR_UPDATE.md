# 侧边栏功能更新说明

## 更新内容

### 1. 新增组件
- **ConfigSidebar.vue** - 配置参数侧边栏（左侧）
- **LogSidebar.vue** - 执行日志侧边栏（右侧）

### 2. 主要特性

#### 位置优化
- 侧边栏从 `top-6` 开始，与"小红书内容生成工作流"标题对齐
- 高度为 `calc(100vh - 3rem)`，避免遮挡顶部内容
- 左侧栏宽度：320px (w-80)
- 右侧栏宽度：384px (w-96)

#### 视觉优化
- **渐变背景**：
  - 左侧栏：`from-bg-primary to-bg-secondary` (从左上到右下)
  - 右侧栏：`from-bg-primary to-bg-secondary` (从右上到左下)
- **玻璃态效果**：`backdrop-blur-sm` 半透明模糊背景
- **边框**：左侧栏右边框，右侧栏左边框
- **阴影**：`shadow-2xl` 深度阴影效果
- **头部**：半透明背景 + 模糊效果 (`bg-bg-primary/50 backdrop-blur-md`)
- **图标**：主题色图标，增强视觉识别

#### 交互优化
- **浮动层级**：`z-40` 侧边栏 + `z-30` 遮罩层
- **遮罩层**：点击遮罩可关闭侧边栏
- **动画效果**：
  - 左侧栏：从左侧滑入/滑出
  - 右侧栏：从右侧滑入/滑出
  - 遮罩层：淡入/淡出
- **切换按钮**：
  - 位于页面右上角
  - 配置参数按钮（齿轮图标）
  - 执行日志按钮（文档图标 + 消息数量徽章）

### 3. 布局变化

#### 原布局（3列）
```
[配置参数 3列] [工作流 6列] [日志 3列]
```

#### 新布局（全宽 + 浮动侧边栏）
```
[工作流可视化 - 全宽]
+ [左侧浮动：配置参数]
+ [右侧浮动：执行日志]
```

### 4. 使用方式

1. **打开配置参数**：点击右上角"配置参数"按钮
2. **打开执行日志**：点击右上角"执行日志"按钮
3. **关闭侧边栏**：
   - 点击侧边栏右上角的 × 按钮
   - 点击遮罩层（侧边栏外的半透明区域）

### 5. 技术实现

- **Vue 3 Composition API**
- **Tailwind CSS** 样式系统
- **Transition 组件** 实现动画
- **响应式状态管理** 控制显示/隐藏

## 优势

1. ✅ **更大的工作流展示区域** - 工作流图可以使用全宽显示
2. ✅ **按需显示** - 不需要时可以隐藏，减少视觉干扰
3. ✅ **浮动设计** - 不影响主内容布局
4. ✅ **优雅的视觉效果** - 渐变背景 + 玻璃态 + 流畅动画
5. ✅ **良好的用户体验** - 直观的交互方式
