## 🔄 完整交互流程

### 1. 标题选择流程
```
1. 用户点击"开始生成"
2. 工作流执行到 title_lab 节点
3. 后端通过 WebSocket 发送 node_complete 消息
4. 前端检测到 title_candidates 数据
5. 自动弹出标题选择对话框
6. 用户选择一个标题
7. 调用 continueGeneration API
8. 工作流继续执行
```

### 2. 人工审核流程
```
1. 工作流执行到 chief_editor 节点
2. 后端通过 WebSocket 发送 node_complete 消息
3. 前端检测到 need_human_review 标志
4. 自动弹出人工审核对话框
5. 用户查看内容和编辑建议
6. 用户选择通过或拒绝
7. 调用 submitHumanReview API
8. 工作流继续执行或重新生成
```

### 3. 结果展示流程
```
1. 工作流执行到 finalize 节点
2. 后端返回 final_post 数据
3. 前端显示结果展示面板
4. 用户可以复制各个部分
5. 用户可以导出为文本文件
6. 用户可以查看图片
```
